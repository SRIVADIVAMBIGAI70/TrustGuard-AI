# TrustGuard AI

AI-powered credibility scoring and spam detection system for professional platforms like LinkedIn.

## Overview
TrustGuard AI analyzes messages and profiles using Machine Learning and NLP to classify interactions as Safe, Suspicious, or Spam.

## Key Features
- AI-powered message classification
- Profile credibility scoring
- Real-time alerts
- Adaptive learning
- Cloud-based scalable architecture
